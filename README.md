# AI Math Solver Cost-Capability Decision

This example demonstrates the core concept of choosing between different AI math models based on problem complexity and a predefined budget. It simulates a 'low-cost, limited capability' model (like Gemma) and a 'high-cost, high capability' model (like Gemini). The script prioritizes cost-effective solutions for simpler problems and only resorts to more powerful, expensive models when necessary and within budget.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
